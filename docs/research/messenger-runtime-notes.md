# Public runtime research and legal boundary

## Scope

The approved Chardin foundation plan records a prior public inspection of Messenger’s deployed browser bundle. It observed Svelte, direct Three.js, postprocessing, custom GLSL, compressed-asset loading, collision-related code, multiple input modes, animation mixing, and positional audio. Those observations describe public runtime signals only; they do not establish or reveal the source architecture.

No Messenger bundle, repository file, shader, model, texture, audio, writing, UI artwork, level layout, or brand asset is included in Chardin. Public clone repositories remain references only: one reportedly mirrors proprietary material, and another has ambiguous licensing because its README claim is not backed by a license file.

## Permitted use

General browser-rendering and interaction techniques may be independently implemented from first principles. Chardin’s shapes, palette, composition, prose, code, and future audiovisual work must be original or have documented redistribution rights. Inspiration is not authorization to reproduce a distinctive artwork or implementation.

## WIL-117 provenance

All visual content in this slice is generated at runtime from original Three.js primitives and authored parameters in this repository: an icosphere Planet, deterministic instanced grass, simple geometric Traveler, lighting, fog, and HTML interface. There are no downloaded assets or copied shaders.
